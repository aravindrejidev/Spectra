## What's New
- A hi-res file with content up to about 25 kHz is no longer called an upsample, because a 44.1 or 48 kHz master can't hold that
- The text report no longer shows "Container: unknown" for raw formats like FLAC
- Dolby Digital, Dolby Digital Plus (Atmos), TrueHD and DTS now show their proper names
- For 5.1 and 7.1 lossy files the estimated bitrate is given per stereo pair, and the inflated-bitrate check no longer misjudges surround streams
- Batch CSV: the warnings column is split into authenticity_flags and mastering_flags
